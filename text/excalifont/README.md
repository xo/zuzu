# Excalifont

`Excalifont-Regular.woff2` is Excalifont, version 1.000, the font of the
look like Excalidraw (D40). It is under the SIL Open Font License 1.1,
which `LICENSE.txt` holds. The license names no Reserved Font Name.
Excalifont comes from the font Virgil, which reserves the name Virgil.

The file comes from <https://github.com/excalidraw/excalidraw>, unchanged.
It is the blob `24ce44aa15c0f18163c5bf9583aac124f8a27aec`, at
`packages/excalidraw/fonts/assets/Excalifont-Regular.woff2` in the commit
`62228e0bbb780d1070a8cf206caa32132d22f19e` and at
`packages/excalidraw/fonts/woff2/Excalifont/Excalifont-Regular.woff2` until
the commit `61623bbeba08fd802d23df46ceb8861c6a9a6180`. It holds 52,296
bytes, and its SHA-256 is
`ee41ec4c06bfa0728665499de6f4b4019e7953119ab20b5aeb5917f1609c3b2a`.

Since that commit, Excalidraw ships the same font as seven files in WOFF2,
one for each range of characters, in `packages/excalidraw/fonts/Excalifont`.
The seven files hold the same 561 characters, with the same outlines and
the same advances, and 64,768 bytes in all. They lose the kerning between
two characters of two files, and the table name, which holds the license.
So zuzu embeds the file before the split.

`LICENSE.txt` holds the copyright and the license of the table name of the
font, entries 0 and 13.
