# D22. The documents name no person

Status: Decided.

zuzu has several maintainers. The maintainers asked on 2026-11-10 that the
documents name no one of them, unlike the other `xo` repositories. A document
writes "the maintainers" for a choice or a request, and a decision gives the
date. An agent that copies text from another `xo` repository changes a name
in it to "the maintainers".

The copyright line of `LICENSE` is not a document. It names the same holder
as the other `xo` repositories, with the years 2015-2026, under the MIT
License. The maintainers decided this on 2026-11-10, answering open
question 9.
