# D3. The plan and the rules come before any code

Status: Decided.

The maintainers asked on 2026-11-10 for the plan to be made before any code
is written. No code of the package is written before the plan is ready, and
a change to the plan is a decision first. The survey pages in
`docs/survey/` and the targets in `docs/targets/` are not code of the
package. They are tools for review, in JavaScript and Python.
