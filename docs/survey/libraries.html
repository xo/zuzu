Chart Library Field Guide

What developers in every language actually reach for, how many chart types each library ships, and whether looks or features decide the winner. Star and download counts were pulled live from GitHub, GitLab, npm, PyPI, CRAN and crates.io on 9 Nov 2026. Qualitative views come from Gemini 3.1 Pro, GPT-6 Astra and DeepSeek V4 Pro, cross-checked against those numbers.

The short answer

Distribution beats beauty. Good defaults are a threshold, not a differentiator.

Driver 1 · Being the default somewhere64.6M

Recharts npm downloads per week, 6× ECharts. It is the engine behind shadcn/ui charts. Matplotlib (159M/mo) is what pandas.plot() calls. Mermaid (25.9M/wk) renders natively in GitHub. None of them won a beauty contest.

Driver 2 · Ergonomics and framework fit8 types

Chart.js ships only 8 chart types but has 67.8k stars, because ten lines of config get you a decent chart. Highcharts ships 90+ types and has 12.5k. Breadth does not predict popularity (see the scatter below).

Driver 3 · License10.2M vs 3.6M

ECharts (Apache-2.0) vs Highcharts (commercial) weekly npm. They are comparably polished and capable. ApexCharts moved to a dual license (free under $2M revenue), which forces a new procurement step at larger companies.

Driver 4 · Performance carves niches4 types

uPlot draws lines, bars, points and bands, with plain defaults. It still runs inside Grafana because it streams huge time series on Canvas. TradingView Lightweight Charts owns finance the same way.

Where aesthetics decidesCustomer-facing

SaaS product UI, journalism, executive decks, quick prototypes. Polish is part of the deliverable there. That is where Nivo, amCharts, Highcharts and ApexCharts sell. Seaborn exists because Matplotlib's defaults were ugly, and it still sits on Matplotlib.

Diagram-as-code, for comparison

Mermaid, Graphviz, PlantUML, D2

These draw structure (nodes, edges, sequences) instead of encoding numbers. People pick them because the source is plain text that diffs in a pull request, the layout engine places everything for you, and Mermaid renders inside GitHub, GitLab, Notion and Obsidian without any build step. Mermaid now also has pie, xychart, sankey, quadrant, gantt, radar and treemap. That covers a burndown in an issue or a pie in a PRD. It does not replace a chart library: there is no live data binding, little interactivity, and large graphs render slowly.

Beyond JavaScript and Python

What other languages use

Outside JS, Python and R, the most common pattern is to wrap a JS engine, usually ECharts (go-echarts, pyecharts, charming for Rust, Echarts-PHP). The alternative is a native rasterizer for server-side images. PHP has no notable native library. Laravel projects wrap Chart.js or ApexCharts, and JpGraph is legacy.

Three flagship models, asked the same question

Do looks drive adoption?

Gemini 3.1 Pro
“Functionality drives adoption. Aesthetics are top-of-funnel marketing.”
  • Chart.js beat D3 on ergonomics, not beauty.
  • Recharts beats the prettier Nivo because the JSX API feels native.
  • ECharts takes enterprise share from Highcharts because it is free.
  • Matplotlib wins on ecosystem gravity despite its dated defaults.
GPT-6 Astra
“Workflow first, capabilities second, aesthetics third, unless visual expression is the product.”
  • Aesthetics is decisive for SaaS UI, journalism, exec decks and prototypes.
  • Underrated: ECharts in the West, Observable Plot, uPlot.
  • Over-recommended: D3 for routine dashboards, Plotly for tiny embeds (payload).
DeepSeek V4 Pro
“Defaults drive adoption; functionality and ecosystem drive retention.”
  • Overrated: Recharts. SVG struggles past about 10k points and the wrapper fights customization.
  • Underrated: D2. Best syntax and layout of the diagram tools, held back by no native GitHub rendering.
  • ECharts and AntV won China through Chinese-first docs, built-in China maps, and being embedded in BI and mini-program platforms (DataV, Quick BI, WeChat, Alipay).

Where they agree, and the tiebreak

All three agree that framework fit, licensing and ecosystem outrank polish once a tool is good enough. The only real split is DeepSeek's claim that looks win the first install. The download data supports a narrower version of that. Looks help a library get tried, but the libraries with the most installs are the ones another tool installs for you: shadcn ships Recharts, pandas calls Matplotlib, GitHub renders Mermaid. The beauty-first options (Nivo at 2.0M/wk, amCharts 5 at 0.59M/wk) sit far below the defaults.

Method: stars come from the GitHub REST API (GitLab for Graphviz). Downloads: npm last week, PyPI last month (pypistats), CRAN last month (cranlogs), crates.io last 90 days. Chart-type counts are first-party built-in series, marks, geoms or traces from each project's docs, rounded where the docs say "~". Treat them as ±20%. Plotters' crates.io number is mostly transitive installs through the criterion benchmarking crate. amCharts is developed in private, so its public repo's star count understates its use.
