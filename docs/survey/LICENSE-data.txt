The data of this folder, in data.js, and the data of the targets in
docs/targets, which read the same file, is a copy of twelve files of
vega-datasets 3.3.1.

vega-datasets: https://github.com/vega/vega-datasets, tag v3.3.1,
commit 08eaed074411eeec211736c73264c2b306cda060. The package is under the
BSD 3-Clause License, as its package.json and datapackage.json state. The
repository holds no LICENSE file of its own.
