Chart Library Comparison

The same real data, drawn by each of the main chart and diagram libraries with its defaults. Read it to see what each library draws by itself, what it needs a plugin for, and what the caller must prepare first. Only the dark mode is set by hand where a library has no dark theme of its own. The colors, fonts, spacing and animation are each library's own.
