# Schemes

This document lists the color schemes that come from the styles of
`github.com/xo/transit/styles` v0.7.8 (D58). The command `test/cmd/schemes` of the test
module writes it, with `theme/schemes.go`. Do not edit it. Run the command
again. "Schemes from upstream themes" in [STYLE.md](STYLE.md) holds the
rules.

There are 176 schemes. 30 of them are families, which take the light
mode from one style and the dark mode from another. A scheme of one style
has one mode. In the other mode, it takes the neutrals of zuzu, and its
colors lift for the dark mode or darken for the light mode. Each neutral
other than `bg` and `text` mixes `text` into `bg`. `theme/licenses/` holds
the license of each source.
